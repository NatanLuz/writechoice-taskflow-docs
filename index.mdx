A **TaskFlow API** é uma API REST para organizar projetos e tarefas. Você pode criar projetos, adicionar e consultar tarefas, alterar seus dados ou status e excluí-las.

## Fluxo de uso

Crie um projeto antes de adicionar tarefas. A resposta da criação fornece o `project_id` necessário para criar e listar tarefas. A criação de tarefa fornece o `task_id` usado para atualizá-la ou excluí-la.

## URL base

```text
https://test-writechoice.onrender.com
```

Todas as operações exigem uma chave de API no cabeçalho `Authorization` como token Bearer. Consulte [Autenticação](/authentication) para instruções de uso seguro.

<Note>
  O servidor pode levar até 60 segundos para responder à primeira requisição. Aguarde antes de tentar novamente.
</Note>
