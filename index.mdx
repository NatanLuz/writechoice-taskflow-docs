The **TaskFlow API** is a REST API for organizing projects and tasks. You can create projects, add and list tasks, update task details or status, and delete tasks.

## How it works

Create a project before adding tasks. The project creation response provides the `project_id` required to create and list tasks. Creating a task returns the `task_id` used to update or delete it.

## Base URL

```text
https://test-writechoice.onrender.com
```

All operations require an API key in the `Authorization` header as a Bearer token. See [Authentication](/authentication) for secure usage instructions.

<Note>
  The server may take up to 60 seconds to respond to the first request. Wait for a response before retrying.
</Note>
