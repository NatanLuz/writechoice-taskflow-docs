---
title: "Autenticação"
description: "Envie sua chave de API TaskFlow com autenticação Bearer e proteja o segredo."
---

Todas as operações exigem uma chave de API válida no cabeçalho HTTP `Authorization`, no formato `Bearer <chave>`.

## Envie o cabeçalho

```http
Authorization: Bearer <sua_chave_de_api>
```

Com cURL, prefira carregar a chave de uma variável de ambiente:

```bash
export TASKFLOW_API_KEY="<sua_chave_de_api>"
curl --request GET \
  --url "https://test-writechoice.onrender.com/projects/<project_id>/tasks" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY"
```

No PowerShell, defina a variável com `$env:TASKFLOW_API_KEY = "<sua_chave_de_api>"` e use `$env:TASKFLOW_API_KEY` no valor do cabeçalho.

## Proteja sua chave

- Não inclua a chave em código-fonte, repositórios, capturas de tela ou exemplos públicos.
- Não compartilhe a chave nem a inclua em URLs. Envie-a somente no cabeçalho `Authorization` por HTTPS.
- Use variáveis de ambiente ou um gerenciador de segredos adequado ao seu ambiente.
- Se uma chave for exposta, procure o responsável pela API para solicitar orientação sobre substituição ou revogação. A especificação não documenta endpoints de gerenciamento de chaves.

## Falhas de autenticação

Uma chave ausente ou inválida resulta em `401 Unauthorized`. Confirme que o cabeçalho tem o prefixo `Bearer`, não contém espaços extras e usa uma chave válida. Consulte [Erros e limitações](/errors).
