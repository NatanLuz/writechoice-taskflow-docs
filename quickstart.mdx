---

This guide walks you through creating a project, creating a task, listing project tasks, updating a task, and deleting it.

## Prerequisites

- A valid API key. See [Authentication](/authentication) for instructions on protecting it.
- cURL installed.

Choose the commands for your terminal. **Do not copy the Bash commands directly into Windows CMD**: variable assignment, variable references, and JSON escaping differ between shells.

### Bash (Linux/macOS)

Set the key in your current terminal. Replace the placeholder with your API key:

```bash
export TASKFLOW_API_KEY="<your_api_key>"
```

### Windows CMD

Set the key in your current Command Prompt session. Replace the placeholder with your API key:

```cmd
set "TASKFLOW_API_KEY=<your_api_key>"
```

Do not share your key or store it in your project source code. Each command sends it in the Bearer authorization header.

<Note>
  When the server is idle, the first request may take up to 60 seconds. Wait for a response before retrying a creation request to avoid creating duplicate resources.
</Note>

## 1. Create a project

The `name` field is required. `description` is optional; this example sends only the required field.

Request JSON:

```json
{
  "name": "Documentation project"
}
```

**Bash (Linux/macOS):**

```bash
curl --request POST \
  --url "https://test-writechoice.onrender.com/projects" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"name":"Documentation project"}'
```

**Windows CMD:**

```cmd
curl --request POST ^
  --url "https://test-writechoice.onrender.com/projects" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%" ^
  --header "Content-Type: application/json" ^
  --data "{\"name\":\"Documentation project\"}"
```

The API returns `201 Created`. Example response with illustrative values:

```json
{
  "project_id": "<project_id>",
  "name": "Documentation project",
  "created_at": "<creation timestamp>"
}
```

Copy `project_id` from the response. In the same terminal, store it in a variable for the following commands. Replace the placeholder with the returned value and omit the `<` and `>` characters.

**Bash (Linux/macOS):**

```bash
export PROJECT_ID="<returned_project_id>"
```

**Windows CMD:**

```cmd
set "PROJECT_ID=<returned_project_id>"
```

## 2. Create a task

`project_id` and `title` are required; `description` is optional. This example sends only the required fields. `PROJECT_ID` must be set in the same terminal.

Request JSON:

```json
{
  "project_id": "<returned_project_id>",
  "title": "Review guide"
}
```

**Bash (Linux/macOS):**

```bash
curl --request POST \
  --url "https://test-writechoice.onrender.com/tasks" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY" \
  --header "Content-Type: application/json" \
  --data "{\"project_id\":\"$PROJECT_ID\",\"title\":\"Review guide\"}"
```

**Windows CMD:**

```cmd
curl --request POST ^
  --url "https://test-writechoice.onrender.com/tasks" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%" ^
  --header "Content-Type: application/json" ^
  --data "{\"project_id\":\"%PROJECT_ID%\",\"title\":\"Review guide\"}"
```

The API returns `201 Created`. New tasks have an initial status of `pending`. Example response with illustrative IDs and timestamps:

```json
{
  "task_id": "<task_id>",
  "project_id": "<project_id>",
  "title": "Review guide",
  "status": "pending",
  "created_at": "<creation timestamp>",
  "updated_at": "<update timestamp>"
}
```

Copy the returned `task_id` and store it for updating and deleting this task. Replace the placeholder with the returned value and omit `<` and `>`.

**Bash (Linux/macOS):**

```bash
export TASK_ID="<returned_task_id>"
```

**Windows CMD:**

```cmd
set "TASK_ID=<returned_task_id>"
```

## 3. List project tasks

The `project_id` from the first response identifies the project whose tasks you want to list.

**Bash (Linux/macOS):**

```bash
curl --request GET \
  --url "https://test-writechoice.onrender.com/projects/$PROJECT_ID/tasks" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY"
```

**Windows CMD:**

```cmd
curl --request GET ^
  --url "https://test-writechoice.onrender.com/projects/%PROJECT_ID%/tasks" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%"
```

The `200 OK` response contains `project_id`, `total`, and the `tasks` array. If the project exists but has no tasks, `tasks` is an empty array.

## 4. Update the task

Use the `task_id` returned when you created the task. This example updates the status. Valid values are `pending`, `in_progress`, and `done`.

**Bash (Linux/macOS):**

```bash
curl --request PATCH \
  --url "https://test-writechoice.onrender.com/tasks/$TASK_ID" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"status":"in_progress"}'
```

**Windows CMD:**

```cmd
curl --request PATCH ^
  --url "https://test-writechoice.onrender.com/tasks/%TASK_ID%" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%" ^
  --header "Content-Type: application/json" ^
  --data "{\"status\":\"in_progress\"}"
```

The `200 OK` response contains the updated task. You can also send `title` or `description`; include at least one of the accepted fields.

## 5. Delete the task

Deletion is permanent. Confirm that `TASK_ID` contains the ID of the task you want to remove.

**Bash (Linux/macOS):**

```bash
curl --request DELETE \
  --url "https://test-writechoice.onrender.com/tasks/$TASK_ID" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY"
```

**Windows CMD:**

```cmd
curl --request DELETE ^
  --url "https://test-writechoice.onrender.com/tasks/%TASK_ID%" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%"
```

The `200 OK` response confirms deletion. The specification does not define an operation to recover a deleted task.
