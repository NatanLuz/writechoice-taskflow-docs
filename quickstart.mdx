---
title: "Início rápido"
description: "Execute o fluxo básico da TaskFlow API com cURL no Bash ou no CMD do Windows."
---

Neste guia, você vai criar um projeto, criar uma tarefa, listar as tarefas do projeto, atualizar a tarefa e excluí-la.

## Pré-requisitos

- Uma chave de API válida. Consulte [Autenticação](/authentication) para saber como protegê-la.
- cURL instalado.

Escolha os comandos para o terminal que está usando. **Os comandos Bash não devem ser copiados diretamente para o CMD do Windows**: a definição de variáveis, a referência a elas e o escape do JSON são diferentes.

### Bash (Linux/macOS)

Defina a chave no terminal atual. Substitua o placeholder pela sua chave:

```bash
export TASKFLOW_API_KEY="<sua_chave_de_api>"
```

### CMD do Windows

Defina a chave no Prompt de Comando atual. Substitua o placeholder pela sua chave:

```cmd
set "TASKFLOW_API_KEY=<sua_chave_de_api>"
```

Não compartilhe a chave nem a salve no código do projeto. Ela será enviada no cabeçalho Bearer em cada comando.

<Note>
  Quando o servidor está inativo, a primeira requisição pode levar até 60 segundos. Aguarde a resposta antes de repetir uma operação de criação, para evitar criar recursos duplicados.
</Note>

## 1. Crie um projeto

O campo `name` é obrigatório. `description` é opcional; este exemplo envia somente o campo obrigatório.

Corpo JSON enviado:

```json
{
  "name": "Projeto de documentação"
}
```

**Bash (Linux/macOS):**

```bash
curl --request POST \
  --url "https://test-writechoice.onrender.com/projects" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"name":"Projeto de documentação"}'
```

**CMD do Windows:**

```cmd
curl --request POST ^
  --url "https://test-writechoice.onrender.com/projects" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%" ^
  --header "Content-Type: application/json" ^
  --data "{\"name\":\"Projeto de documentação\"}"
```

A API responde com `201 Created`. Exemplo de resposta, com valores ilustrativos:

```json
{
  "project_id": "<project_id>",
  "name": "Projeto de documentação",
  "created_at": "<data e hora de criação>"
}
```

Copie o valor de `project_id` da resposta. No mesmo terminal, guarde-o em uma variável para reutilizá-lo nos próximos comandos. Substitua o placeholder pelo valor recebido, sem os sinais `<` e `>`.

**Bash (Linux/macOS):**

```bash
export PROJECT_ID="<project_id recebido>"
```

**CMD do Windows:**

```cmd
set "PROJECT_ID=<project_id recebido>"
```

## 2. Crie uma tarefa

`project_id` e `title` são obrigatórios; `description` é opcional. Este exemplo envia somente os campos obrigatórios. A variável `PROJECT_ID` precisa estar definida no mesmo terminal.

Corpo JSON enviado:

```json
{
  "project_id": "<project_id recebido>",
  "title": "Revisar guia"
}
```

**Bash (Linux/macOS):**

```bash
curl --request POST \
  --url "https://test-writechoice.onrender.com/tasks" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY" \
  --header "Content-Type: application/json" \
  --data "{\"project_id\":\"$PROJECT_ID\",\"title\":\"Revisar guia\"}"
```

**CMD do Windows:**

```cmd
curl --request POST ^
  --url "https://test-writechoice.onrender.com/tasks" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%" ^
  --header "Content-Type: application/json" ^
  --data "{\"project_id\":\"%PROJECT_ID%\",\"title\":\"Revisar guia\"}"
```

A API responde com `201 Created`. A tarefa recebe status inicial `pending`. Exemplo de resposta, com IDs e datas ilustrativos:

```json
{
  "task_id": "<task_id>",
  "project_id": "<project_id>",
  "title": "Revisar guia",
  "status": "pending",
  "created_at": "<data e hora de criação>",
  "updated_at": "<data e hora de atualização>"
}
```

Copie o `task_id` retornado e guarde-o para atualizar e excluir esta tarefa. Substitua o placeholder pelo valor recebido, sem `<` e `>`.

**Bash (Linux/macOS):**

```bash
export TASK_ID="<task_id recebido>"
```

**CMD do Windows:**

```cmd
set "TASK_ID=<task_id recebido>"
```

## 3. Liste as tarefas do projeto

O `project_id` da primeira resposta identifica o projeto cujas tarefas serão listadas.

**Bash (Linux/macOS):**

```bash
curl --request GET \
  --url "https://test-writechoice.onrender.com/projects/$PROJECT_ID/tasks" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY"
```

**CMD do Windows:**

```cmd
curl --request GET ^
  --url "https://test-writechoice.onrender.com/projects/%PROJECT_ID%/tasks" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%"
```

A resposta `200 OK` contém o `project_id`, o total e a lista `tasks`. Se o projeto existir, mas ainda não tiver tarefas, `tasks` será uma lista vazia.

## 4. Atualize a tarefa

Use o `task_id` retornado ao criar a tarefa. Este exemplo altera o status; os valores permitidos são `pending`, `in_progress` e `done`.

**Bash (Linux/macOS):**

```bash
curl --request PATCH \
  --url "https://test-writechoice.onrender.com/tasks/$TASK_ID" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{"status":"in_progress"}'
```

**CMD do Windows:**

```cmd
curl --request PATCH ^
  --url "https://test-writechoice.onrender.com/tasks/%TASK_ID%" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%" ^
  --header "Content-Type: application/json" ^
  --data "{\"status\":\"in_progress\"}"
```

A resposta `200 OK` contém a tarefa atualizada. Também é possível enviar `title` ou `description`; envie pelo menos um dos campos aceitos.

## 5. Exclua a tarefa

A exclusão é permanente. Confirme que `TASK_ID` contém o ID da tarefa que deseja remover.

**Bash (Linux/macOS):**

```bash
curl --request DELETE \
  --url "https://test-writechoice.onrender.com/tasks/$TASK_ID" \
  --header "Authorization: Bearer $TASKFLOW_API_KEY"
```

**CMD do Windows:**

```cmd
curl --request DELETE ^
  --url "https://test-writechoice.onrender.com/tasks/%TASK_ID%" ^
  --header "Authorization: Bearer %TASKFLOW_API_KEY%"
```

A resposta `200 OK` confirma a exclusão. A especificação não define uma operação para recuperar uma tarefa excluída.
